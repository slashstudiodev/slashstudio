# Слэш Студия — заявки с сайта в Telegram

Клиент заполняет форму на сайте и нажимает **«Отправить заявку»**.
Заявка сразу приходит в вашу Telegram-группу **«Заявки с сайта»** и хранится там.
Клиенту ничего не нужно копировать.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | сайт с формой и кнопкой «Отправить заявку» |
| `lib/lead-core.mjs` | проверяет заявку и отправляет её в Telegram |
| `api/lead.mjs` | серверная функция для Vercel |
| `netlify/functions/lead.mjs` | серверная функция для Netlify |
| `netlify.toml` | настройки для Netlify |

Токен бота хранится **только в настройках хостинга**. В коде сайта его нет, поэтому украсть его со страницы нельзя.

---

## Шаг 1. Группа для заявок

1. **Перезапустите бота**: закройте окно бота и запустите `C:\ads_bot\start.bat` заново.
2. В Telegram создайте группу **«Заявки с сайта»** и добавьте в неё **@SlashStudioBot**.
3. Напишите в группе команду **`/chatid`**.
   Бот ответит ID группы — число вида `-1001234567890`. Сохраните его, оно нужно в шаге 3.

> Если бот отвечает «Не понял вас» — значит, запущена старая версия. Перезапустите бота.

---

## Шаг 2. Загрузите файлы в ваш репозиторий

Новый репозиторий не нужен.

1. Откройте ваш репозиторий на **github.com**.
2. Нажмите **Add file → Upload files**.
3. Перетащите файлы из папки `C:\slash_site` — в ту же папку репозитория, где лежит ваш `index.html`:

   | Где сайт | Что загрузить |
   |---|---|
   | **Vercel** или **GitHub Pages** | `index.html`, папки `api` и `lib` |
   | **Netlify** | `index.html`, папки `netlify` и `lib`, файл `netlify.toml` |

4. Внизу страницы нажмите **Commit changes**.

Старый `index.html` заменится новым. Остальные файлы репозитория не изменятся.

> **Важно:**
> - Если вы меняли `index.html` после 18.10 — перенесите эти правки в новый файл, иначе они пропадут.
> - Если в репозитории уже есть свой `netlify.toml` — не заменяйте его, а допишите в раздел `[build]` строку:
>   `functions = "netlify/functions"`

---

## Шаг 3. Настройте хостинг

Во всех вариантах нужно добавить три переменные:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота — тот же, что в `C:\ads_bot\.env` |
| `TELEGRAM_CHAT_ID` | ID группы из шага 1 |
| `ALLOWED_ORIGIN` | адрес вашего сайта, например `https://slash-studio.vercel.app` |

### Сайт на Vercel

1. Если репозиторий ещё не подключён: **vercel.com → Add New → Project →** выберите ваш репозиторий **→ Deploy**.
2. **Settings → Environment Variables** — добавьте три переменные из таблицы.
3. **Deployments → ⋯ → Redeploy**, чтобы настройки применились.

### Сайт на Netlify

1. **Site configuration → Environment variables** — добавьте три переменные из таблицы.
2. **Deploys → Trigger deploy**.

### Сайт на GitHub Pages

GitHub Pages не умеет запускать серверный код, поэтому функцию запустит Vercel — **из того же репозитория**.
Сайт при этом продолжит работать на GitHub Pages.

1. Подключите ваш репозиторий к Vercel и добавьте переменные — как в разделе «Сайт на Vercel».
   В `ALLOWED_ORIGIN` укажите адрес сайта на GitHub Pages, например `https://username.github.io`.
2. В `index.html` найдите строку:
   ```js
   var LEAD_ENDPOINT = '/api/lead';
   ```
   и замените на адрес функции на Vercel:
   ```js
   var LEAD_ENDPOINT = 'https://ВАШ-ПРОЕКТ.vercel.app/api/lead';
   ```
3. Загрузите изменённый `index.html` в репозиторий (**Commit changes**).

---

## Шаг 4. Проверка

Откройте сайт, заполните форму и нажмите **«Отправить заявку»** — через секунду заявка появится в группе.

| Что пишет форма | Что сделать |
|---|---|
| «Приём заявок не настроен на сервере» | не заданы переменные из шага 3 или не сделан Redeploy |
| «Не удалось доставить заявку» | проверьте `TELEGRAM_CHAT_ID` и что бот состоит в группе |
| «Нет связи с сервером» | неверный `LEAD_ENDPOINT` или функция не загружена (нет папок `api` / `lib`) |

---

## Защита от спама

- скрытое поле-ловушка: роботы его заполняют, люди — нет;
- форма, отправленная быстрее чем за 3 секунды, отбрасывается;
- заявки принимаются только с вашего сайта (`ALLOWED_ORIGIN`);
- длина полей ограничена, HTML в тексте заявки обезвреживается.
